# Security review, 29 Oct 2026

Internal review of Echo 0.1.0. No external audit.

## Scope

The whole app at 0.1.0: manifest, `Engine.kt` (routing, recording, Opus, levels), `MainActivity.kt`, `About.kt`, build configuration and CI. Grid: OWASP MASVS-L1 for storage, network, platform interaction and code quality.

## Findings

**Network.** No INTERNET permission in the merged release manifest. No dependency adds one. CI fails if it appears.

**Permissions.** `RECORD_AUDIO`, asked on the first test with the reason on screen, and `MODIFY_AUDIO_SETTINGS`, used only for `MODE_IN_COMMUNICATION` and `setCommunicationDevice` during a test. Both listed in `docs/permissions.txt`, checked by CI.

**Storage.** None. The take is a `ShortArray` in memory, dropped in `onStop`. No preferences, no files, no database. `allowBackup=false` and `dataExtractionRules` exclude everything anyway.

**Audio state.** `CallSession` is `AutoCloseable`; the previous mode is restored and the communication device cleared in `close()`, reached on success, error and cancellation.

**Exported components.** `MainActivity` (launcher) only. `AboutActivity` is not exported.

**Codec.** Platform Opus through `MediaCodec`, no native code shipped by the app.

**Signing.** One release key, kept outside the repository. Certificate SHA-256 in `SECURITY.md`, shown in About from the installed APK.

## Remaining

- The signing key is a file, not a hardware key. Moving it to hardware is planned.
- No external audit.

Next review: before 29 Apr 2027, or at any change to permissions, storage or audio routing.
